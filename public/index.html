plan.md format 
# Build plan

- [ ] First task
- [x] Done task
- [ ] Third task (depends: 1, 2)

Use one checklist item per task. Looparr tracks only checklist lines: - [ ], - [x], * [ ], and + [ ].

Add (depends: 1, 2) after a task to require those checklist numbers first. Numbers are 1-based; #1 also works. Old plans without dependencies stay valid.

The first unchecked item still runs next. If its dependencies are missing, part of a cycle, or not complete, Start reports a clean error and does not reorder or skip tasks. Headings and notes stay in the file, but Looparr does not run them.
